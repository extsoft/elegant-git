# eg hook list

`hook list` lists configured hook file paths.

```bash
eg hook list
```

There are no arguments. It prints the path of every hook file that currently exists — personal
and repo-tracked, including leftover files in the old layout — and a command to edit each one.
Nothing is asked. The layout itself is on the [hook files](reference/hook-files.md) page.
