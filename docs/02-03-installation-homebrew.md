# Using Homebrew

On macOS or Linux with [Homebrew](https://brew.sh/):

```bash
brew install extsoft/tools/elegant-git
```

That puts `eg` on your `PATH`. To pick up a newer release:

```bash
brew upgrade elegant-git
```
