# "self" guide

The `self` object is about this machine: the Elegant Git installation and your Git
configuration — global identity, aliases, and the shared memory file that holds workspaces
and the repository registry.

`eg self` with no action prints the action list. There is nothing to detect from context, so an
action is always required.

## Actions

- [`configure`](05-01-self-configure.md) — Configures Git and the Elegant Git installation.
- [`list`](05-02-self-list.md) — Shows Elegant Git installation and Git configuration state.
- [`doctor`](05-03-self-doctor.md) — Diagnoses and repairs the Elegant Git installation and Git configuration.
