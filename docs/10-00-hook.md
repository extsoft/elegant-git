# "hook" guide

The `hook` object does the file handling for scripts that run before and after Elegant Git
commands. Where those files live, how they are named, and when they run is on the
[hook files](reference/hook-files.md) page.

`eg hook` with no action prints the action list. There is nothing to detect from context, so an
action is always required.

## Actions

- [`list`](10-01-hook-list.md) — Lists configured hook file paths.
- [`new`](10-02-hook-new.md) — Creates a new hook file.
- [`edit`](10-03-hook-edit.md) — Opens a hook file in your editor.
